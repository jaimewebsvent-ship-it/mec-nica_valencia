# Mecánica Reus – landing page

Sitio estático (HTML + Tailwind por CDN). Diseño exportado de Google Stitch.

## Ejecutar en local
    cd mecanica-reus
    python3 -m http.server 8000
    # abrir http://localhost:8000

(Alternativa con Node: `npx serve .`)

Requiere conexión a internet: Tailwind, fuentes e iconos se cargan por CDN.
